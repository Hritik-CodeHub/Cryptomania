# 📈 Cryptomania – Track, Analyze & Explore Your Favorite Coins Seamlessly

 **CryptoMania** is a full-featured cryptocurrency dashboard and tracker built using **React.js**, integrated with **Firebase** for user authentication and a **Firestore database** for persistent user watchlists. It fetches live data from the **CoinGecko API** and displays it in clean, interactive charts using **Chart.js**.

---

## 🛠️ Tech Stack

- **React.js** – Component-based architecture
- **Firebase** – Authentication (Email/Google) + Firestore DB
- **CoinGecko API** – Real-time crypto market data
- **Chart.js** – Data visualization of price history
- **Material UI** – Beautiful, responsive UI components
- **HTML, CSS, JavaScript**

---

## ✨ Key Features

✅ **Real-time Market Data**  
– Fetches and displays up-to-date coin prices, market caps, volume, and rankings.

✅ **Firebase Authentication**  
– Supports Email/Password and Google Sign-in securely.

✅ **Watchlist Management**  
– Logged-in users can add/remove coins to a personal watchlist stored in Firestore.

✅ **Interactive Price Charts**  
– View historical trends of each cryptocurrency with time-frame filters.

✅ **Coin Search & Filter**  
– Instantly search for any coin and filter results by market ranking.

✅ **Responsive UI**  
– Clean design optimized for mobile and desktop using Material UI.
